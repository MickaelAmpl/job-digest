# Этап 6: сопроводительное письмо - план на утверждение (09.10.2026)

Статус: черновик, ждёт правок Миши. Работа начинается только по его команде.

## Цель
Из вакансии с отметкой «Интересно» по кнопке в боте за 1-3 минуты получить сопроводительное письмо на английском:
- текстом в чат, чтобы вставить в поле анкеты;
- PDF в стиле резюме (та же шапка, шрифт, одна страница);
- таблица «требование из объявления -> какое предложение письма его закрывает -> из какого факта банка».
Письмо никогда не отправляется работодателю инструментом. Отправляет Миша сам.

## Как устроено письмо (из research/research_cover_letters.md: Кембридж, MIT, LSE, karriere.at, AMS)
- 4 абзаца, 250-350 слов, жёсткий потолок 380, одна страница.
- Тема: "Application: <точное название вакансии> (<номер, если есть>)".
- Обращение: имя из объявления («Ihre Ansprechpartnerin: Frau X» -> "Dear Ms X"); пол только из Frau/Herr в объявлении, никогда по имени. Нет имени -> "Dear <Company> hiring team".
- Абзац 1 (крючок): вакансия + одна конкретная деталь о компании или продукте, дословно взятая из текста объявления + кто он в одном предложении.
- Абзац 2 (доказательства): 2 требования из объявления, на каждое - действие и результат из банка фактов.
- Абзац 3 (третье требование или честный мостик для слабого места): например, нет титула PM на бумаге -> что он делал по сути.
- Абзац 4 (закрытие): один конкретный следующий шаг, разрешение на работу / часы / старт - по решению ниже, без "would", "hope".
- Подпись: имя, почта, телефон, LinkedIn - копируются из шапки резюме кодом.

## Проверки в коде (не только в промпте)
1. Объём 250-350 слов, больше 380 - провал; одна страница PDF.
2. Точное название вакансии и компании есть в тексте.
3. Деталь о компании - дословная подстрока текста объявления, иначе предложение выбрасывается (лучше без детали, чем с выдуманной).
4. Все числа только из facts.md и резюме; стоп-лист из facts.md (ChatGPT, Bybit, GTM, A/B-тесты и т.д.).
5. Стоп-лист клише: "I am writing to apply", "passionate", "team player", "dynamic", "perfect fit", "I believe I could", "excited to" и ещё ~15 из исследования.
6. Ни одно предложение не повторяет строку резюме дословно (сверка с адаптированной версией, если она есть, иначе с базовой).
7. Не больше 2 из 4 абзацев начинаются с "I"; в последних двух предложениях нет "would/hope".
8. Зарплата - только если объявление просит: минимум из объявления, пересчитанный на его часы.
9. Отдельный вызов-проверяльщик сверяет каждое свободное предложение с банком фактов; неподтверждённое - откат к библиотечному тексту, в чат строка «откатил».

## Бот
- Кнопка «Сопроводительное письмо» на карточке «Интересно» и под готовым резюме.
- Тот же фоновый обработчик, что у резюме (бот не зависает), та же защита от двойного нажатия.
- Требования из объявления берутся из уже сделанного разбора резюме, если он есть - один вызов модели меньше.
- Повторное нажатие - новая версия, старые хранятся. Письмо привязано к вакансии в учёте, видно в /report.
- Нет текста объявления - бот просит вставить, как с резюме (текст уже сохраняется в data/cv/<job>/pasted.txt).
- Стоимость: $0 сверху, 1-2 вызова sonnet по подписке на письмо.
